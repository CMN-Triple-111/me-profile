# Matt Essentials Solutions (`me-profile`)

Official web platform and founder portfolio for **Matt Essentials Solutions** (`www.mattessentials.online`) and **Chiiko Matthew Nswana**, crafted with a high-motion, pastel-and-obsidian agency aesthetic inspired by [QClay Design](https://qclay.design/).

## Key Pages & Assets

- [`index.html`](./index.html) — **Matt Essentials Solutions Studio Homepage**:
  - **QClay Lerp Cursor & Magnetic UI**: Smooth `requestAnimationFrame` follower ring with contextual labels (`Play Reel!`, `Let's Talk!`, `Interact`, `Visit Site ↗`) and magnetic hover buttons.
  - **Full-Screen Animated Menu Modal**: Interactive navigation overlay with a color-morphing video preview card (`#dad2f4`, `#effbf9`, `#fce38a`, `#f7c3b4`, `#8de746`).
  - **Hero Section & SVG Eye**: Staggered multi-line typography, 5.0 client rating badge, authentic QClay-style SVG eye with eyelashes, blinking eyelids, cursor-tracking pupil, rotating circular text badge, and scroll-scaling showreel container (`Q1.mp4`, `Q2.mp4`).
  - **"What About Matt Essentials?" Horizontal Scroll Section**: 3 QClay pastel cards (`#dad2f4`, `#effbf9`, `#fce38a`) with double decorative circles and parallax pill videos that work on both desktop (sticky horizontal track) and mobile.
  - **"WE CREATE" Kinetic Marquee & 3-Stage Interface Showcase**: Interactive switcher between *01. UX & Wireframe*, *02. Holistic UI System*, and *03. Full-Stack & Mobile* with floating collaborator cursors and a 6-card Core Expertise bento grid.
  - **Selected Works Live Browser Frames**: Interactive production previews for **GNS Corporations**, **ZYOA Organization**, **St. Moven's School**, and **Ewana Environmental Consultant** with scroll-guard shields and one-click live interaction.
  - **QClay Interactive Project Request Form**: Multi-select service pills, budget range pills, validation, and a celebratory **"Thank You! 🤝"** modal.
- [`cv.html`](./cv.html) — **Chiiko Matthew Nswana Developer Portfolio & Profile**.
